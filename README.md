\# Office Management System



\## Project Description

The Office Management System is a web application used to manage office employees, departments, attendance, and tasks.



\## Technologies Used

\- HTML

\- CSS

\- JavaScript



\## Features

\- Employee Management

\- Employee Details

\- Attendance Management

\- Department Management

\- Task Management



\## How to Run

1\. Download the project.

2\. Open the project folder.

3\. Open `index.html` in your browser.



\## Conclusion

This project helps manage office activities easily and efficiently.
